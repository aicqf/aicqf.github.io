# 最新传奇发布网（静态站）

## 结构

所有文件都在同一层目录，上传到 `aicqf.github.io` 仓库根目录即可：

- `index.html` 首页
- `xin.html` `dan.html` `he.html` `wei.html` `bx.html` `fg.html` 六个栏目
- `xin-1.html` … `fg-20.html` 120 篇文章
- `kf.html` 开服表 · `all.html` 全站目录 · `about.html` 关于 · `search.html` 站内搜索 · `404.html`
- `style.css` `app.js` `img01.jpg`–`img30.jpg` `robots.txt` `sitemap.xml`

## 部署

1. 新建或打开仓库 `aicqf/aicqf.github.io`
2. 把本目录所有文件上传到仓库根目录
3. Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`，目录 `/ (root)`
4. 访问 https://aicqf.github.io

## 内容

6 栏目 × 20 篇 = 120 篇，单篇约 1100 字；30 张 126×126 配图。
文章标题不含栏目名，栏目页标题不含站点品牌。
